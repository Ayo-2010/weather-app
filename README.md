# Skycast

Current conditions and a 7-day forecast for any city.

## Features

- Search any city by name, or pick from 1,000 cities across 142 countries
- Backdrop that changes with the weather
- Toggle between Celsius and Fahrenheit
- Powered by the free Open-Meteo API, no key required

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html     markup
styles.css     styling
locations.js   the 1,000-city list
script.js      behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
